# Documents

The following documents are taken as the source of truth for defining the Classification scheme represented in this
project.

* [DoD Information Security Program: Marking of Information](./MarkingOfInformation/README.md)
* [Intelligence Community Markings System Register and Manual](./ICMarkingsSystem/README.md)

Both these documents cover much of the same information. The
[DoD Information Security Program: Marking of Information](./MarkingOfInformation/README.md) document is more resent,
and is referred to as a source from documents current as of 2025, and so is considered the primary source document
in this library.

The [Intelligence Community Markings System Register and Manual](./ICMarkingsSystem/README.md) covers some markings in
greater detail. It is presumed to be correct where it does not conflict with the later document.
